# V6.54 — Universal Evolution Governance & Lightweight Agent Profile

Status: IMPLEMENTATION / NOT ACQUIRED

V6.54 gives every ChaCha DEV agent a lightweight, machine-readable evolution profile.

The profile is governance metadata, not a performance score.

For each of the 35 agents it records:
- platform vs project-local scope;
- declared capabilities;
- current total / production / benchmark measurement coverage;
- missing dimensions;
- executable adapter availability;
- next evidence action;
- production maturity target;
- candidate ownership and promotion guards;
- contract fingerprint.

Unknown evidence remains unknown.

Project-local Technology Radar remains project-local and cannot be promoted as a global platform agent.

Curator and Intendant receive governance profiles but remain PROFILE_ONLY until a real local executable adapter is independently qualified.

Fourth adapter wave:
- Acceptance Engineer — real acceptance-engine;
- Contract Integrator — real architecture-specialist contract runtime;
- Integration Architect — real architecture-specialist contract runtime;
- Ergonome — real UX Planning Engine.

The Observation Bus Health Controller now fingerprints the universal profile policy. A later governance-policy change requests bus reassessment.

Automatic external spend remains 0 EUR.


## Universal component evolution governance

V6.54 extends the agent profile into a class-aware governance index.

The same governance depth is not copied onto every object.

- FULL_AGENT: agent scorecard + observation + Technology Watch + Logician + benchmark + SHADOW/PILOT.
- LIGHTWEIGHT_PROJECT_AGENT / LIGHTWEIGHT_EMBEDDED_AGENT: minimal local runtime controls only; heavy evolution intelligence remains central.
- CORE_PLATFORM_COMPONENT: component fingerprint, self-health, Technology Watch, Logician, regression, SHADOW/PILOT and rollback.
- CONNECTOR_ADAPTER: protocol/version/auth/scope/health/compatibility/canary/rollback; no fake agent scorecard or agent learning loop.
- RUNTIME_INFRASTRUCTURE: version, health, security, resource/cost, compatibility, canary and rollback.
- OWNED_ARTIFACT: schemas/configs/prompts/templates inherit the owner component and never receive an independent agent or promotion loop.

Every indexed evolvable component has exactly one candidate owner.
Architecture Council remains final authority.

## Future Agent Foundry inheritance

Every newly created agent manifest now receives an `evolution_profile`.

Project-local / ephemeral agents additionally receive `lightweight_runtime_profile`.

They therefore enter the Observation Bus, learning uplink, Technology Watch revalidation and controlled promotion model automatically from creation.

## Lightweight application agents

Embedded application probes do not carry a second ChaCha DEV brain.

They carry only:
identity/version/capabilities, least-privilege permissions, zero-default budget, health, telemetry, provenance, learning uplink, termination and compatibility.

Technology Watch, Logician, Foundries, benchmark orchestration, promotion decisions and Architecture Council remain centralized.

This prevents architectural duplication while preserving continuous evolution.
