# V6.47 — Agent Fleet Observatory & Evidence-Backed Optimization

Status: IMPLEMENTATION / NOT ACQUIRED

## Why V6.47 exists

V6.46 created the continuous evolution framework, but its score engine accepted caller-supplied metrics and previously defaulted missing dimensions to 50.

That is not acceptable for a real fleet audit.

V6.47 makes agent optimization evidence-backed.

## Fundamental rule

**Unknown is not 0. Unknown is not 50. Unknown is UNKNOWN.**

An agent cannot be optimized, deprecated or promoted merely because evidence is missing.

If measurement coverage is insufficient, its recommendation is `MEASURE_FIRST`.

## Runtime evidence sources

The Fleet Observatory reads existing ChaCha DEV evidence without mutating it:

- Task Graphs for role ownership;
- Run Records for actual executions, retries and Guardian verdicts;
- independently verified Task Results for accuracy/evidence quality;
- Component Confidence for exact-agent learning/confidence state.

PREPARED tasks are not execution evidence.
Ambiguous task-role mappings are not attributed.
Unverified results never become accuracy evidence.

## Measurable dimensions today

Where sufficient evidence exists:

- accuracy;
- evidence quality;
- robustness;
- efficiency;
- authority discipline;
- learning quality.

Other dimensions remain UNMEASURED until a trustworthy observation source exists.

## Two separate queues

### Optimization Queue
Contains only agents with enough measurement coverage and evidence-backed debt:
- BLOCK_AND_REVIEW;
- SHADOW_CANDIDATE;
- OPTIMIZE.

### Measurement Queue
Contains:
- MEASURE_FIRST;
- MEASURE_MORE.

Unmeasured high-risk agents are instrumented before low-risk agents.

## Authority

The observatory is read-only.
Agents do not own their score.
Logician can challenge but not promote.
Agent Foundry owns candidate materialization.
Technology Watch remains mandatory.
Guardian and Sentinel remain mandatory.
Architecture Council remains final authority.
Automatic external spend remains 0 EUR.
