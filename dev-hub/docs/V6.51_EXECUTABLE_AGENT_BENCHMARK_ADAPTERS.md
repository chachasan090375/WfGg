## Evidence boundary

Benchmark results are always:
- BENCHMARK_ONLY;
- production_truth_eligible = false;
- BENCHMARK_VERIFIED only after a separate oracle evaluates the output;
- exact-revision bound;
- Technology Watch freshness gated;
- zero external automatic spend;
- forbidden from writing to the canonical Agent Observation Bus.

Promoted benchmark evidence may fill a dimension that is still UNMEASURED. It never overwrites a production/runtime measurement.

A failing benchmark is still useful negative evidence. Failure does not disappear merely because the candidate performed poorly.

## Real code under test

Guardian uses the real remediation runtime.
Sentinel uses the real technical audit engine on isolated Git repositories.
Bastion uses the real incident-response action router with every side effect replaced by an isolated test double.
Autonomous Recovery uses the real recovery orchestrator with Agent Observation Bus publication disabled inside the benchmark.

Unsupported agents are reported NO_EXECUTABLE_ADAPTER, never FAILED.
