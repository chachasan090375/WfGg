# V6.56 — Sixth Adapter Wave & Production-Weighted Maturity

Status: IMPLEMENTATION / NOT ACQUIRED

V6.56 adds a production-weighted evidence maturity model and executable adapters for:
- Test Engineer
- Performance Engineer
- SRE / Observability Engineer

## Production-weighted maturity

Total dimension coverage remains visible, but maturity is now explicitly weighted:
- production evidence weight: 70%
- benchmark evidence weight: 30%

The weights are normalized from policy.

A 100% benchmark-only scorecard therefore has 30% production-weighted maturity and remains BENCHMARK_HEAVY.

Candidate evidence maturity now requires both:
- minimum production dimension coverage;
- minimum production-weighted maturity.

KEEP also requires a higher production-weighted maturity threshold.

## Sixth adapter wave

The three new adapters reuse the real architecture-specialist contract runtime:
- Test Engineer: testing / test-strategy focus
- Performance Engineer: performance / capacity focus
- SRE / Observability Engineer: observability focus

No parallel agent runtime is introduced.

Their existing verified production history remains authoritative. Benchmark evidence fills only unmeasured dimensions.

## Safety

Benchmark-only evidence cannot materialize a candidate.
Production and benchmark dimensions cannot overlap.
Production evidence retains precedence.
Architecture Council remains final authority.
Automatic external spend remains 0 EUR.
