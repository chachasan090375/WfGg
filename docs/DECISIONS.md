# Décisions figées dans V0.2.0

1. Le Portail devient un module autonome.
2. Train n'est pas modifié pendant la construction initiale du Portail.
3. Tous les joueurs utilisent un code à 6 chiffres pour établir leur première session sur un appareil.
4. Chaque joueur possède son propre profil et ses propres préférences.
5. La langue du profil est FR / IT / EN / ES.
6. Le modèle conserve les rangs R1-R5 plutôt qu'un rôle générique `PLAYER`.
7. R1/R2/R3 : profil + modules.
8. R4/R5 : mêmes fonctions + onglet Alliance.
9. R5 : droits supplémentaires pour la gestion des comptes R5.
10. Le dernier R5 actif d'une alliance ne peut pas être désactivé/dégradé.
11. L'onboarding Profil doit être validé avant l'ouverture des modules depuis le Portail.
12. L'avatar est individuel et facultatif.
13. Les réglages Alliance appartiennent à l'alliance, pas au profil personnel du R4/R5.
14. Les contrôles de droits sont effectués côté backend en plus du masquage d'interface.
15. L'authentification commune à Train/Guides/Simulateur sera une phase ultérieure.
